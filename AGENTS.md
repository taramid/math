
## Tech Stack & Environment
- **PHP**: 8.4 (Always use `declare(strict_types=1);` in new files).
- **Framework**: Symfony 8.1 (Follow standard Symfony Best Practices, Attributes, DI).
- **Database & Cache**: Doctrine ORM, PostgreSQL, Redis.
- **Frontend**: Twig, Tailwind CSS, Symfony UX / Turbo.


## Guidelines for AI
- **Code Standards**: Write clean, typed, self-documenting PHP.
- **Surgical Diffs**: Implement only the minimum necessary changes to fulfill the request.
- **Respect Existing Code**: Do not refactor, clean up, or delete unrelated config keys, comments, or code without explicit instructions.
- **End-to-End Integration**: Updating primary templates or components with minimal working examples is encouraged to demonstrate the feature works.
